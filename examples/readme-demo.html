01 / What it is

A small publishing layer between an agent and your team.

Agent-ready

A shared Codex and Claude Code skill builds one responsive HTML file and publishes it in the same workflow.

Access-controlled

Google sign-in protects private artifacts. Owners manage people, domains, and public visibility per page.

Updateable

Reuse a slug to replace the HTML while keeping the same link and existing sharing rules.

Self-contained

Artifacts inline their assets and make no network requests, so the delivered page stays portable.

Browser-managed

Upload, replace, download, delete, and adjust access without reaching for an admin console.

Sandboxed

Published HTML runs in an isolated iframe, separated from the authenticated application around it.

02 / Use it

Ask, publish, share.

STEP 1

Describe the artifact

Ask for a visual report, implementation plan, dashboard, comparison, or walkthrough.

STEP 2

Let the skill publish

The agent creates a self-contained page, uploads it privately, and opens the resulting URL.

STEP 3

Choose its audience

Use Access in the viewer bar to add people, allow a domain, or publish the link for everyone.

03 / Commands

One prompt—or one terminal command.

Ask Codex

Use codex-artifacts to create and
publish a visual architecture report
for this repository.

Publish existing HTML

node scripts/publish.mjs ./report.html \
  --title "Architecture report"

# Add --public only when intended.
04 / Access

Visibility is a per-artifact decision.

PeopleGrant access to exact verified Google email addresses.
DomainsAllow every signed-in account whose email ends in a chosen domain.
PublicRemove the sign-in requirement for artifacts meant for everyone.
