03 / DECISION

Why Lakebed

Use the platform; avoid rebuilding its plumbing.

Lakebed already offered hosted deployment, identity, a server runtime, database transactions, environment secrets, and a stable subdomain. Its object storage intentionally blocks HTML, so artifact contents are split into database chunks below the platform’s value limit. The tradeoff is a compact personal service: 512 KiB per artifact inside Lakebed’s current 1 MiB total state allowance.
